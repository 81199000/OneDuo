登录 Apple ID

🔒 安全说明
  • 账号和密码直接发送到苹果官方服务器（gsa.apple.com），不经过我们或任何第三方。
  • 用的是苹果自己的加密登录协议，密码本身不会在网络上明文传输。
  • 本软件不保存密码，只在你电脑上保存苹果返回的登录凭证，可随时点「退出」清除。
  • 签名核心基于开源项目 Impactor（MIT 协议），代码公开可查。
另外，苹果要求登录时附带一份"模拟设备"信息，这份信息由一个公共开源服务器提供。它只负责生成设备信息，看不到你的账号和密码。
💡 建议用 Apple ID 小号：免费签名会在账号里生成开发证书、登记你的手机，免费账号还有数量限制（同时最多 3 个 App，证书会互相顶掉）。用小号不影响你主号的 iCloud、购买记录。
